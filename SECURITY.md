# Security Policy

## Supported Versions

The default `main` branch is the maintained directory. This does not imply that the third-party submodules listed here are supported or maintained by this project.

## Reporting a Vulnerability

Please do not publish credentials, exploit details, or sensitive personal information in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a private report. Otherwise, contact the maintainer through the contact method listed on the GitHub owner profile.

This repository is primarily a catalog of external projects. For vulnerabilities in an upstream tool, contact that project's maintainers using its own security policy. Do not assume this repository can triage or coordinate an upstream vulnerability.

No encrypted security endpoint or guaranteed response time is claimed.
