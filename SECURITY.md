# Security Policy

## Scope

This repository primarily indexes third-party repositories as Git submodules. It does not operate, maintain, or provide security support for those upstream projects.

## Reporting a problem in this catalogue

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, use the contact method listed on the maintainer's GitHub profile. Do not include exploit details, credentials, or personal data in a public issue.

## Upstream vulnerabilities

Report vulnerabilities in a third-party tool to that project's maintainers using its own security policy. A listing here is not an endorsement and does not establish a support relationship with upstream maintainers.

No response time or remediation guarantee is offered.
